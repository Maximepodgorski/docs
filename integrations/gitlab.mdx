## Setup

1. Go to **Settings \> Integrations \> GitLab**
2. Click **Connect** and authorize Lyse
3. Select your default project
4. Click **Save**

## What gets created

When you mention `@Lyse` in Slack, a GitLab issue is created with:

- Title generated from the conversation
- Description with full context
- Created in your default project

## Configuration

Change your default project anytime in **Settings \> Integrations \> GitLab**.

## Troubleshooting

### Connection failed

- Verify your token has the correct scopes: `read_user` and `api`
- Make sure the token hasn't expired

![Figma Dark](/images/integrations/figma-dark.png)

## Setup

1. Go to **Settings \> Integrations \> Figma**
2. Click **Connect Figma**
3. Authorize Lyse when Figma asks

## Usage

Include a Figma link when you mention `@Lyse`:

```
The button spacing looks off. https://figma.com/design/abc123?node-id=1-2 @Lyse
```

Lyse extracts:

- Component name
- Component properties (variants, booleans)
- Direct link to the node

<Info>
  This context is included in the created task.
</Info>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Component not found">
    - Check the link points to an existing node
    - Verify your Figma account has access to the file
  </Accordion>
  <Accordion title="Missing properties">
    Properties are only extracted for components, not regular frames.
  </Accordion>
  <Accordion title="OAuth expired">
    Disconnect and reconnect in **Settings \> Integrations \> Figma**.
  </Accordion>
</AccordionGroup>

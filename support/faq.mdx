## General

<AccordionGroup>
  <Accordion title="What is Lyse?">
    Lyse is an AI assistant that creates tasks from Slack conversations. Mention `@Lyse` in a thread and a task is created in your issue tracker.
  </Accordion>
  <Accordion title="Which issue trackers are supported?">
    Linear, GitHub Issues, Jira, and GitLab Issues.
  </Accordion>
  <Accordion title="How much does it cost?">
    Check [<u>getlyse.com/pricing</u>](https://getlyse.com/pricing) for current plans.
  </Accordion>
</AccordionGroup>

## Usage

<AccordionGroup>
  <Accordion title="How do I create a task?">
    Mention `@Lyse` in any Slack thread. You can add instructions like `@Lyse create a bug task`.
  </Accordion>
  <Accordion title="Can I add design context?">
    Yes. Include a Figma link in your message and Lyse extracts component details automatically.
  </Accordion>
  <Accordion title="Does Lyse work in private channels?">
    Yes, but you need to add Lyse to the channel first. Go to channel settings and add Lyse as a member.
  </Accordion>
  <Accordion title="Can multiple people use Lyse?">
    Yes. Anyone in your Slack workspace can mention `@Lyse`. Tasks are created in the issue tracker connected by the account admin.
  </Accordion>
</AccordionGroup>

## Integrations

<AccordionGroup>
  <Accordion title="Can I connect multiple issue trackers?">
    Currently, Lyse connects to one issue tracker per account.
  </Accordion>
  <Accordion title="Do I need admin permissions?">
    You need admin permissions in Slack to install the Lyse app. For issue trackers, you need permission to install apps or create issues.
  </Accordion>
  <Accordion title="How do I change my default project?">
    Go to **Settings \> Integrations**, select your issue tracker, and update the default project.
  </Accordion>
</AccordionGroup>

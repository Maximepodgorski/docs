# AutoClick pour Mac

Petite app avec fenêtre : choisis l'intervalle, clique sur **Démarrer**. Elle déplace la souris et clique à intervalle régulier pour éviter l'inactivité.

## Installation (une seule fois, sans taper de commande)

1. Double-clique sur **Construire AutoClick.command**
   (si macOS refuse : clic droit → Ouvrir → Ouvrir).
   La première fois, macOS peut proposer d'installer les outils de développement : accepte, puis relance le fichier.
2. `AutoClick.app` apparaît dans ce dossier. Glisse-la dans **Applications** si tu veux.

## Utilisation

1. Ouvre **AutoClick** (clic droit → Ouvrir la première fois).
2. Clique sur **Démarrer**. macOS demande l'autorisation **Accessibilité** :
   Réglages Système → Confidentialité et sécurité → Accessibilité → active AutoClick, puis relance l'app.
3. **Arrêter** ou ferme la fenêtre pour stopper.

Le clic a lieu où se trouve la souris : laisse-la sur une zone neutre.
